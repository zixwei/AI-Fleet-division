## 替补链

- 每条替补链允许无限增加成员，不设人数上限。
- muse 必须出现在每条替补链中，排在 guse 之前（作 guse 之前的替补）；guse 仍是每条替补链的最后一环。
- 付款类任务永不自动替补。
- 默认任务分配顺序与故障替补顺序是两套不同机制，不能混为一谈：默认分配按并行空位分配（先 wuse、再 xuse、再 muse，三个独立 bot 可同时干活，见规则库 DECISIONS.md 第 2 节 2026-11-10 12:58 ET 条），故障替补只在成员做不了、掉线或额度耗尽时按替补链顺序依次顶上。
